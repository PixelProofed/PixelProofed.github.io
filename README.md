# PixelProofed.github.io

Starter site for a GitHub Pages worldbuilding hub.

## Pages

- `index.html` - home page
- `setting.html` - setting overview with subsection anchors
- `bot-info.html` - bot reference page
- `styles.css` - shared theme and layout
- `script.js` - mobile sidebar behavior

## Publish On GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings on GitHub.
3. Find the Pages section.
4. Set the site to deploy from your main branch and the repository root.
5. Save, then wait for GitHub Pages to publish the site.
